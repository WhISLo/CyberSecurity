# Проект: Проведение атак и их детекция с помощью Wazuh

| **Поле** | **Заполнение** |
|----------|----------------|
| **Название проекта** | Проведение атак (брутфорс, сканирование, реверс-шелл) и их детекция с помощью Wazuh |
| **ID документа** | PRJ-003 |
| **Дата начала** | 17.08.2026 |
| **Дата окончания** | 18.08.2026 |
| **Исполнитель** | WISL |
| **Цель проекта** | Отработать навыки проведения базовых атак и научиться анализировать их обнаружение в SIEM. |
| **Используемое ПО и инструменты** | Kali Linux, Ubuntu, Windows 10, Wazuh, Nmap, Hydra, msfvenom, netcat, планировщик задач, реестр Windows |
| **Описание среды** | Атакующий (Kali, 10.10.10.100) атакует Ubuntu (10.10.10.20) и Windows 10 (10.10.10.201). Wazuh установлен на Ubuntu, агенты активны на всех узлах. |
| **План действий (краткий)** | 1. SSH-брутфорс: hydra -l root -P rockyou.txt ssh://10.10.10.20. 2. Сканирование портов: nmap -sS -p- 10.10.10.201. 3. Реверс-шелл: генерация reverse.exe (msfvenom), передача на Windows 10, запуск, закрепление в автозапуске и планировщике. |
| **Результаты** | Все три атаки были зафиксированы Wazuh: • SSH-брут – множество событий уровня 10 (правила 5712, 40111). • Сканирование – Wazuh зафиксировал события ID 60776 и 61110. • Реверс-шелл – обнаружены скачивание файла и исходящее соединение на порт 4444. Также отработаны техники закрепления: запись в реестр, создание задачи в планировщике (успешно), создание службы (ошибка 1053, так как EXE не сервисный). |
| **Скриншоты/логи (ссылки)** | Скриншоты терминалов, алертов Wazuh. Логи в папке `logs/`. |
| **Выводы** | Отработаны навыки проведения атак, понимание того, как SIEM детектирует каждую из них. Выявлены слабые места: отсутствие мониторинга папки C:\Users\Public, изменений в автозагрузке и планировщике. |
| **Рекомендации** | Усилить мониторинг запуска процессов из общедоступных папок, включить аудит изменений в реестре и планировщике задач. Использовать более агрессивные настройки сканирования. |
