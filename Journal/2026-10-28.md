## Тема: Построение SOAR-системы (Wazuh + Shuffle + VirusTotal + Gmail)

Сегодня мы наконец-то собрали полноценную автоматизацию реагирования (SOAR). Это был очень тяжелый путь, но результат того стоил. Теперь Wazuh не просто логирует события, но и сам проверяет IP атакующего и присылает уведомление на почту.

### 1. Реанимация Wazuh
Утром Wazuh снова лежал (`API is down`). 
*Причина:* Слетели права на `wazuh.yml` и `ossec.conf` после наших ночных экспериментов.
*Решение:* Научились правильно перезаписывать файлы внутри контейнеров через `cat | docker exec -i`. Исправили `run_as: true` в дашборде. Больше не падает.

### 2. Эпопея с интеграцией Wazuh ➔ Shuffle
Написали кастомный скрипт `custom-shuffle.sh` на Bash (Python скрипт молча падал из-за отсутствия библиотеки `requests`).
*Ошибка:* Wazuh создавал файлы алертов в `/tmp`, но Shuffle их не получал.
*Решение:* Выяснили, что нужно было запустить скрипт вручную, чтобы увидеть ошибку. Переделали интеграцию на Bash с командой `curl`. Это сработало! Данные полетели в вебхук.

### 3. Настройка Gmail и Email
*   Штатный узел Gmail не подошел (требует OAuth2).
*   Сгенерировали 16-значный «Пароль приложения» в Google.
*   *Ошибка:* SMTP выдавал ошибку `<False> is not a valid RFC...` и `dict object has no attribute encode`.
*   *Решение:* В узле Email жестко прописали email получателя (без переменных) и добавили текст перед переменными. Порт 587 (TLS) заработал.

### 4. Настройка логики в Shuffle (Condition и VirusTotal)
*   *Ошибка:* Узел `Shuffle Tools` падал с ошибкой `Function if_else_routing doesn't exist`.
*   *Ошибка:* Связи между узлами постоянно рвались (`Skipped because it's not under the startnode`).
*   *Ошибка:* VirusTotal выдавал 404, потому что в алертах `sudo` нет IP.
*   *Ошибка:* Python-узел выдал `SyntaxError` на команду `return`.

### 5. Финальный успех
Выстроили цепочку: **Webhook ➔ Python ➔ VirusTotal ➔ Email**. 
Сгенерировали реальную ошибку SSH (Rule 5710, Level 5). 
**Результат:** VirusTotal проверил IP `10.10.10.203` (ответ 200), а на почту пришло письмо: 
> *Обнаружен инцидент! Правило: sshd: authentication failed. Хост: ubunta Уровень опасности: 5 IP источника: 10.10.10.203*

Мы настроили фильтрацию в Python через `exit(0)` и `exit(1)`, чтобы отсеивать низкие уровни (например, `sudo`). 

**Планы на завтра:** 
Автоматизация ответных действий (Active Response). Научим Shuffle автоматически блокировать IP атакующего через Wazuh API на 5-10 минут, чтобы в лаборатории была настоящая защита.
