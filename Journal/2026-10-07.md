## Расширение диска Ubuntu

Изначально диск был 25 ГБ, занят на 100%.  
В VirtualBox изменил размер основного диска `ubuntu-clone-disk004.vdi` через **Менеджер виртуальных носителей** (левая панель).  
Поставил 60 ГБ (потом оказалось 99 ГБ).  

Внутри Ubuntu:
```bash
sudo growpart /dev/sda 2
sudo resize2fs /dev/sda2
df -h
Теперь /dev/sda2 — 99 ГБ, свободно 74 ГБ.

Перед этим чистил место:

bash
sudo apt clean
sudo journalctl --vacuum-size=200M
sudo docker system prune -a --volumes -f
