# 2026-10-27

## Тема: Настройка SOAR (Shuffle) и автоматизация уведомлений из Wazuh

Сегодня был очень тяжелый, но продуктивный день. Мы пытались построить автоматизацию: чтобы Wazuh ловил события, отправлял их в Shuffle, тот проверял IP через VirusTotal и присылал нам письмо на почту.

### 1. Реанимация Wazuh
Начали с того, что Wazuh не работал после вчерашних экспериментов с конфигом (`ERROR: API is down`). 
*Выяснили:* После копирования `ossec.conf` через `docker cp` сбились права доступа, а также не хватало самого скрипта интеграции. 
*Сделали:* Написали кастомный скрипт `custom-shuffle.py` на Python. Скопировали в контейнер. Выставили права `chown root:wazuh` и `chmod 750`. Исправили права на сам `ossec.conf`. Перезапустили. Wazuh поднялся, API заработал.

### 2. Тест вебхука
Отправили тестовый `curl`-запрос из контейнера Wazuh прямо в Shuffle. Увидели в Shuffle входящие данные (JSON). Значит, связь есть.

### 3. Эпопея с отправкой Email
Настроили узел `Email` (SMTP) в Shuffle:
*   Пробовали узел `Gmail` — не подошел, там нужен OAuth2.
*   Сгенерировали 16-значный «Пароль приложения» в Google.
*   Порт 465 (SSL) не работал, переключились на **587 (TLS)**.
*   *Ошибка 1:* `'dict' object has no attribute 'encode'` — передавали целый объект `$exec` в тему/тело. *Решение:* Написали обычный текст и добавили переменные.
*   *Ошибка 2:* `<False> is not a valid RFC 53...` — использовали переменную для получателя, и когда предыдущий узел падал, она подставляла `False`. *Решение:* Жестко прописали свой email в поле `Recipient`.
*   Письма начали приходить!

### 4. Битва с узлом Condition (Логика)
Пытались добавить узел, чтобы фильтровать алерты (например, не отправлять письма на каждый `sudo`).
*   Интерфейс Shuffle оказался невероятно запутанным. Искали узел `Condition`, нашли только `Shuffle Tools`.
*   *Ошибка:* При попытке соединить узлы вылезала `Can't make branch to starting node` (Shuffle запрещает создавать петли).
*   *Ошибка:* Узел `Shuffle Tools` выдал `Function if_else_routing doesn't exist`. Оказалось, это баг облачной версии Shuffle.
*   *Решение:* Удалили проблемный узел. Заменили его на обычный узел `Python`.

### 5. Финальный прогон и успех
Построили цепочку: **Webhook ➔ Python ➔ VirusTotal ➔ Email**.
*   Сначала узлы выдавали `Skipped because it's not under the startnode`. Это мы неправильно запускали тест (через общую кнопку Run, а надо через сам Webhook).
*   *Ошибка:* В коде Python неправильно назвали переменную или условие, из-за чего фильтрация срабатывала некорректно.
*   Убрали условие для теста и запустили.
*   **Успех!** Цепочка отработала от начала до конца. VirusTotal вернул статус 200 и проверил IP (10.10.10.20). Письмо успешно ушло на почту.

### 6. Итоги и план на завтра
Сейчас мы получили уже 2 уведомления на почту (без работающего условия). Завтра первым делом нужно починить условие в узле Python, чтобы отсеивать мусорные события (severity < 3), а затем сгенерировать реальную атаку с Kali (SSH-брутфорс), чтобы проверить цепочку на реальном IP атакующего. Дальше будем добавлять Active Response (блокировку IP).
