Конспект-отчет за 2026-10-20: Фундаментальные основы кибербезопасности
Цель: Систематизировать знания о ключевых фреймворках (OWASP, MITRE ATT&CK, NIST CSF) и понять их применение для построения эшелонированной обороны (Blue Team).

1. OWASP Top 10 (2021) — Карта веб-уязвимостей
Этот список от OWASP (Open Worldwide Application Security Project) — некоммерческого фонда, основанного в 2001 году, — описывает наиболее критичные риски для веб-приложений. Понимание этих категорий необходимо для анализа защищенности веб-приложений, с которыми мы работали в Juice Shop.

Ключевые категории (изученные):

A01: Broken Access Control (Нарушенный контроль доступа): Пользователь получает доступ к данным или функциям, на которые у него нет прав. (Пример: IDOR в Juice Shop).

A02: Cryptographic Failures (Ошибки в криптографии): Слабое или отсутствующее шифрование конфиденциальных данных.

A03: Injection (Внедрение кода): Ввод пользователя интерпретируется как код или команда (SQL, XSS и др.). (Пример: SQL-инъекции в Juice Shop).

A05: Security Misconfiguration (Неправильная конфигурация): Ошибки в настройках безопасности приложения или сервера.

A06: Vulnerable and Outdated Components (Уязвимые и устаревшие компоненты): Использование библиотек и ПО с известными уязвимостями.

A10: Server-Side Request Forgery (SSRF): Приложение заставляет сервер выполнить запрос к внутреннему ресурсу от имени пользователя.

2. MITRE ATT&CK — Модель действий противника
Это база знаний, которая структурирует тактики и техники, используемые злоумышленниками. Она делится на три основные матрицы:

Enterprise: Для корпоративных сетей (Windows, Linux, macOS, облака).

Mobile: Для мобильных устройств (iOS, Android).

ICS: Для промышленных систем управления.

Ключевые элементы:

Тактики (Tactics): Высокоуровневые цели атакующего (например, Initial Access, Execution, Persistence).

Техники (Techniques): Конкретные способы достижения тактики (например, Phishing для Initial Access).

Инструменты и ресурсы для работы с ATT&CK:

ATT&CK Navigator: Инструмент для визуализации покрытия и оценки защищенности.

Red Canary Atomic Red Team: Библиотека тестов для имитации действий злоумышленников.

MITRE Cyber Analytics Repository (CAR): База знаний по аналитике для детектирования.

3. NIST Cybersecurity Framework (CSF) — Стратегия управления рисками
Это структурированный подход к управлению киберрисками, который состоит из трех частей (Ядро, Уровни, Профили). Ядро фреймворка включает в себя пять ключевых функций:

Identify (Определяйте): Понимание того, какие активы, системы и данные необходимо защищать, и какие риски для них существуют.

Protect (Защищайте): Разработка и внедрение мер безопасности для обеспечения доступности и защиты сервисов.

Detect (Выявляйте): Создание и внедрение мер по своевременному обнаружению событий безопасности.

Respond (Реагируйте): Действия, предпринимаемые при обнаружении инцидента (сдерживание, анализ, устранение).

Recover (Восстанавливайте): Меры по восстановлению正常工作 и снижению ущерба после инцидента.

4. Практические аспекты: От разведки до инцидента
Изученные материалы также затронули практические шаги атакующего, которые защитник должен уметь распознавать.

Reconnaissance (Разведка): Активное сканирование портов (например, nmap) для выявления сервисов и их версий. Это соответствует техникам семейства Active Scanning в MITRE ATT&CK.

Resource Development (Развитие ресурсов): Подготовка инфраструктуры для атаки — аренда VPS, настройка C2-серверов, создание веб-шеллов (Web Shells) для удаленного управления.

Сценарий инцидента: Классический паттерн, который должна детектировать система защиты: Сканирование портов -> Успешная аутентификация -> Действия в системе. Обнаружение корреляции этих событий с одного IP-адреса является ключевой задачей для SIEM.

5. Стратегия Blue Team: Как «перекрыть кислород»
На основе NIST CSF и концепции эшелонированной обороны (Layered Defense), действия Blue Team выстраиваются следующим образом:

Mindset (Образ мышления): Постоянная бдительность, проактивная защита и обеспечение устойчивости систем.

Hardening (Усиление): Приведение систем в соответствие с лучшими практиками (CIS Benchmarks) для снижения поверхности атаки. Это включает фильтрацию исходящего трафика, контроль приложений и ограничение прав пользователей.

Detection Engineering (Инженерия обнаружения): Создание и настройка правил в SIEM (например, Wazuh) для выявления конкретных техник ATT&CK.

Incident Response (Реагирование на инциденты): Четкий план действий при обнаружении инцидента, включающий сдерживание (Containment), искоренение (Eradication) и восстановление (Recovery) с минимальным влиянием на бизнес.

💎 Итог
Сегодняшнее изучение заложило теоретический фундамент. Понимание OWASP Top 10 объясняет, что мы ищем в веб-приложениях. MITRE ATT&CK дает нам общий язык для описания действий противника и как их детектировать. NIST CSF предоставляет структуру для построения всего процесса защиты и реагирования. Вместе эти фреймворки формируют основу для зрелой программы кибербезопасности.
