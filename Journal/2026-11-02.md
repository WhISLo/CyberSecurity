## Тема: Миграция Shuffle в локальную сеть и настройка Active Response

Сегодня мы планировали просто «донастроить» автоматическую блокировку IP в SOAR, но в итоге пришлось полностью менять архитектуру, столкнувшись с лимитами облачных сервисов и «болячками» Docker.

### 1. Поиск ключей к Wazuh API и ручной тест Active Response
Для работы Shuffle нужен был токен Wazuh API. Долго мучились с ошибками `401 Unauthorized` и `Invalid token`. 
*Выяснили:* Токены живут всего 15 минут. А также нашли правильные креды для API: логин `wazuh-wui`, пароль `MyS3cr37P450r.*-`. 
*Проверка:* Отправили вручную `PUT` запрос через `curl` на `https://10.10.10.20:55000/active-response?agents_list=004`. Wazuh ответил успехом (`"message": "AR command was sent"`). Блокировка на уровне API работает!

### 2. Провал в Shuffle Cloud и переход на Local
При попытке настроить узел HTTP в Shuffle Cloud мы наткнулись на жесткое ограничение бесплатного тарифа: доступна только 1 Environment (Среда), и переключить её с облака на локальный агент нельзя. 
*Решение:* Решили развернуть локальную Open Source версию Shuffle на Ubuntu, чтобы снять все лимиты. Склонировали репозиторий, запустили `docker-compose up -d`.

### 3. Битва с базой данных OpenSearch
Установка Shuffle не запускалась, бесконечно висел экран «Waiting for database».
*Ошибка №1:* Конфликт портов. Wazuh Indexer уже занял порт `9200`. 
*Решение:* В `docker-compose.yml` изменили проброс порта для `shuffle-opensearch` на `9400:9200`.
*Ошибка №2:* `lookup shuffle-opensearch ... server misbehaving`. Бэкенд Shuffle не мог найти базу по имени.
*Решение:* Добавили явный параметр `hostname: shuffle-opensearch` в конфиг и убрали `SHUFFLE_SWARM_CONFIG=run`. Выставили права `chown -R 1000:1000 shuffle-database` и `shuffle-apps`.

### 4. Проблема с отсутствующими приложениями (Apps)
Локальный Shuffle запустился, но в поиске не было ни `HTTP`, ни `Email` (SMTP). Кнопка синхронизации с GitHub выдавала ошибку `authentication required` и `404 Not Found`.
*Решение:* Зашли напрямую в папку `~/Shuffle/shuffle-apps` на хосте. Скачали официальный архив с приложениями Shuffle с GitHub (`python-apps/archive/refs/heads/master.zip`), распаковали и скопировали все `.json` файлы в папку. Перезапустили контейнеры. Приложения появились!

### 5. Итог дня и задел на завтра
Мы успешно развернули локальный Shuffle, загрузили в него нужные узлы и подготовили почву для финальной сборки цепочки. Осталось только прописать настройки внутри узлов (URL, методы, Basic Auth для Wazuh и SMTP для Gmail).

*Дополнительная задача на завтра:* Firefox на Ubuntu дико лагает (висит по 4-5 минут). Скорее всего, дело в Snap-версии. Будем сносить Snap и ставить нормальный пакет из PPA, а также крутить настройки ускорения в VirtualBox.
