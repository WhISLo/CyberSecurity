# 2026-11-02

## Тема: Автоматическое реагирование (Active Response) в SOAR

Целью на сегодня было завершить настройку SOAR — научить Shuffle не просто присылать письма, а автоматически блокировать IP-адреса атакующих через Wazuh Active Response. Битва была тяжелой, но мы почти у цели.

### 1. Починка Wazuh Dashboard (снова)
Утром Wazuh снова выдал ошибку `API is down` и не пускал в дашборд.
*Причина:* В файле `wazuh.yml` в контейнере слетела настройка `run_as: true`, и сбились права доступа после предыдущих правок.
*Решение:* Попытались скопировать файл через `docker cp`, но получили ошибку `device or resource busy` (файл был занят Docker volume). Обошли это через `cat ~/wazuh.yml | sudo docker exec -i ...`. Исправили владельца файла через `chown`. Дашборд заработал. 

### 2. Лимиты Shuffle Cloud
При попытке переключить выполнение задач с облака на локальный агент (Lab-Ubuntu) выяснилось, что бесплатная версия Shuffle Cloud позволяет использовать только 1 Environment (Среду выполнения). Переключить её с Cloud на Lab-Ubuntu нельзя, пока не отключишь Cloud, а отключить нельзя, пока не выберешь другую.
*Решение:* Развернули **локальную (Open Source) версию Shuffle** прямо на Ubuntu через `docker-compose`. Это сняло все лимиты.

### 3. Проблема с Orborus (Worker dispatch timeout)
После запуска локального Shuffle, задачи висели в статусе `EXECUTING`. В логах Orborus было: `Worker dispatch timeout`.
*Причина:* Флаг `--network host`, который мы добавили ранее, изолировал Orborus от контейнеров-воркеров, которые он создавал.
*Решение:* Пересоздали контейнер `shuffle-orborus` без флага `--network host`. Очередь задач очистилась.

### 4. Поиск верных кредов для Wazuh API
Для Active Response нужен токен. Попытки через `wget` и `curl` в контейнере выдавали `401 Unauthorized`.
*Решение:* Нашли правильную пару. Логин — `wazuh-wui`, пароль — `MyS3cr37P450r.*-`. 
Проверили вручную через `curl` с `PUT` запросом на `active-response`. Wazuh ответил успехом: `{"message": "AR command was sent to all agents", "error": 0}`. Значит API работает и блокировка `firewall-drop` выполняется.

### 5. Последний рубеж: Ошибка 401 в узле Shuffle
Сейчас цепочка Webhook ➔ Condition ➔ Wazuh Block IP ➔ Email работает. Условие (Condition) отсекает события ниже 7 уровня.
*Ошибка:* Узел `Wazuh Block IP` (HTTP) выдает `401 Unauthorized: No authorization token provided`.
*Причина:* При переходе на локальную версию Shuffle настройки Basic Auth (логин/пароль) в узле HTTP слетели.
*План:* Завтра нужно заново вписать `wazuh-wui` и пароль в настройки узла HTTP в Shuffle, сохранить и запустить тестовый SSH-брутфорс с Kali. Как только HTTP-узел вернет `200 OK`, IP Kali будет автоматически заблокирован в `iptables` на Ubuntu.

**Итог:** Мы развернули локальный SOAR, победили сетевые проблемы Docker и доказали, что Wazuh API принимает команды на блокировку. Завтра останется только "подружить" с этим API сам Shuffle.
