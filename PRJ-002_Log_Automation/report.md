# Проект: Автоматизация сбора логов и интеграция с Git

| **Поле** | **Заполнение** |
|----------|----------------|
| **Название проекта** | Автоматизация сбора логов и версионирование с Git |
| **ID документа** | PRJ-002 |
| **Дата начала** | 08.07.2026 |
| **Дата окончания** | 09.07.2026 |
| **Исполнитель** | WISL |
| **Цель проекта** | Настроить автоматическую передачу логов с Windows и Kali на центральный сервер, а оттуда – в Git-репозиторий с ротацией старых файлов. |
| **Используемое ПО и инструменты** | PowerShell, Bash, SCP, SSH, Git, cron, планировщик задач Windows |
| **Описание среды** | На Windows настроен Start-Transcript для логирования всех команд PowerShell; по завершении сессии логи копируются через SCP на Ubuntu (пользователь vboxuser). На Kali используется script для логирования терминальных сессий, копирование через SCP по выходу. На Ubuntu логи сохраняются в /srv/logs/, затем автоматически пушатся в GitHub через cron-скрипт. |
| **План действий (краткий)** | 1. Настройка SSH-ключей для беспарольного SCP с Windows/Kali на Ubuntu. 2. Создание профиля PowerShell с Start-Transcript и функцией копирования при завершении. 3. На Kali: создание скрипта start_log_session.sh и добавление scp в .bash_logout. 4. На Ubuntu: создание папки /srv/logs/, инициализация Git-репозитория. 5. Написание скрипта push_logs.sh для коммита и пуша, добавление в cron. 6. Настройка ротации (удаление логов старше 7 дней). |
| **Результаты** | Логи со всех машин автоматически собираются на Ubuntu, пушатся в GitHub каждый час. Старые логи удаляются, экономя место. |
| **Скриншоты/логи (ссылки)** | Скриншоты логов в папках, пример файла .bash_logout, cron-задания. Логи в папке `logs/`. |
| **Выводы** | Получен навык автоматизации рутинных задач SOC, работы с Git, SSH, планировщиками. |
| **Рекомендации** | Можно добавить шифрование логов, настроить алертинг при сбое копирования. |
