# Проект: Развёртывание лабораторной среды для кибербезопасности

| **Поле** | **Заполнение** |
|----------|----------------|
| **Название проекта** | Развёртывание лабораторной среды для кибербезопасности |
| **ID документа** | PRJ-000 |
| **Дата начала** | 03.07.2026 |
| **Дата окончания** | 07.07.2026 |
| **Исполнитель** | WISL |
| **Цель проекта** | Создать изолированную виртуальную лабораторию для отработки навыков пентеста и SOC-аналитики |
| **Используемое ПО и инструменты** | VirtualBox, Windows Server 2022, Windows 10, Windows 11, Ubuntu 22.04, Kali Linux, Astra Linux |
| **Описание среды** | 5 виртуальных машин в VirtualBox с гибридной сетью (NAT для интернета + Host-Only для внутреннего общения). IP-адреса: DC (10.10.10.10), Ubuntu-Wazuh (10.10.10.20), Win10 (10.10.10.201), Win11 (10.10.10.202), Kali (10.10.10.100). Настроены Active Directory, DNS, DHCP на Windows Server. |
| **План действий (краткий)** | 1. Установка VirtualBox и настройка Host-Only сети. 2. Установка всех ОС. 3. Настройка статических IP. 4. Настройка AD, DHCP на Windows Server. 5. Подключение всех машин к домену. 6. Проверка связности. |
| **Результаты** | Полностью рабочая лаборатория с изолированной сетью, доступом в интернет через NAT. Все машины пингуются, домен работает. |
| **Скриншоты/логи (ссылки)** | Скриншоты сетевых настроек, ipconfig, ping. Логи в папке `logs/`. |
| **Выводы** | Отработан навык построения лабораторной инфраструктуры, настройки сетей и доменных служб. |
| **Рекомендации** | Для повышения реалистичности можно добавить firewall, прокси, несколько подсетей. |
