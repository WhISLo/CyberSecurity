# Проект: OSINT-разведка с использованием SpiderFoot

| **Поле** | **Заполнение** |
|----------|----------------|
| **Название проекта** | OSINT-разведка с использованием SpiderFoot |
| **ID документа** | PRJ-004 |
| **Дата начала** | 18.08.2026 |
| **Дата окончания** | 18.08.2026 |
| **Исполнитель** | WISL |
| **Цель проекта** | Собрать открытую информацию о собственных цифровых активах (email, никнеймы, телефон) для оценки цифровой приватности и отработки навыков OSINT. |
| **Используемое ПО и инструменты** | SpiderFoot, VirusTotal, Shodan, AbuseIPDB, AlienVault OTX, theHarvester |
| **Описание среды** | Kali Linux с установленным SpiderFoot. Интегрированы API-ключи VirusTotal, Shodan, AbuseIPDB, AlienVault OTX. |
| **План действий (краткий)** | 1. Настройка API-ключей в SpiderFoot. 2. Запуск сканов по email (viad03@mail.ru, maslmen385@gmail.com). 3. Запуск сканов по никнеймам (WWWisL, wwwislav). 4. Запуск скана по номеру телефона (+79172812199). 5. Анализ результатов, выявление утечек. |
| **Результаты** | • Email viad03@mail.ru найден в утечках на bolshayaperemena.online, dns-shop.ru, text.ru. • Никнеймы не дали значимых связей (аккаунты неактивны или приватны). • Телефон не найден в открытых базах. • ВирусТотал и Shodan не показали результатов, так как цели были не IP/домены, а email и ники. |
| **Скриншоты/логи (ссылки)** | Логи SpiderFoot в формате CSV (прилагаются). |
| **Выводы** | SpiderFoot эффективен для поиска утечек email. Для поиска аккаунтов по username лучше использовать Sherlock. Телефон в открытых источниках не обнаружен – хорошо с точки зрения приватности. |
| **Рекомендации** | Использовать Sherlock для более глубокого поиска аккаунтов, регулярно проверять себя на HaveIBeenPwned. |
