# Проект: Установка и настройка SIEM Wazuh

| **Поле** | **Заполнение** |
|----------|----------------|
| **Название проекта** | Установка и настройка SIEM Wazuh в лабораторной среде |
| **ID документа** | PRJ-001 |
| **Дата начала** | 07.07.2026 |
| **Дата окончания** | 08.07.2026 |
| **Исполнитель** | WISL |
| **Цель проекта** | Развернуть SIEM-систему для централизованного сбора и анализа логов со всех узлов лаборатории |
| **Используемое ПО и инструменты** | Docker, Docker-Compose, Wazuh (Indexer, Manager, Dashboard), Ubuntu 22.04, Wazuh-агенты для Windows и Linux |
| **Описание среды** | На Ubuntu (10.10.10.20) установлен Wazuh через Docker (single-node). Агенты установлены на Windows Server, Win10, Win11 и Kali. Все агенты подключены к менеджеру, логи передаются по TCP порт 1514. |
| **План действий (краткий)** | 1. Установка Docker и Docker-Compose. 2. Клонирование репозитория Wazuh-Docker. 3. Генерация сертификатов и запуск контейнеров. 4. Установка агентов на все машины. 5. Настройка ossec.conf для указания менеджера. 6. Проверка появления агентов в веб-интерфейсе. |
| **Результаты** | Wazuh доступен по https://10.10.10.20, все агенты активны, логи собираются. Созданы базовые правила корреляции (например, для SSH-брута). |
| **Скриншоты/логи (ссылки)** | Скриншоты дашборда, список агентов. Логи установки в папке `logs/`. |
| **Выводы** | Освоена установка SIEM, работа с Docker, настройка агентов. Навык, востребованный в SOC. |
| **Рекомендации** | Настроить дополнительные правила для конкретных угроз, интегрировать с внешними источниками (VirusTotal, AbuseIPDB). |
